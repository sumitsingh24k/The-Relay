# Your feedback on Vaani

Source: student-provided notes from a genuine Vaani exploration. The exact visit date was not recorded.

## What stood out

The Teacher AI and Memories features stood out most. Teacher AI makes voice-agent building easier because requirements can be described in natural language instead of manually configuring every part. The clarification process and ability to review prompt changes before accepting them were particularly useful.

Memories also stood out because an agent can retain relevant context from previous calls, reducing the need for customers to repeat themselves. The call-screening solution was interesting because it addresses a practical telephony problem.

## What confused me

Initially, it was difficult to distinguish Knowledge from Memories: it was not immediately clear how company-level information differs from customer-specific conversation history. A clearer guided explanation of the full journey - agent creation, prompt, voice, tools, testing, and deployment - would help. The Teacher AI readiness score and the meaning of each score also need clearer explanation.

## What I would change

I would add a guided onboarding walkthrough for creating, configuring, testing, and deploying a first voice agent.

I would also add Knowledge Freshness and Accuracy Monitoring. It should detect policy/pricing/document changes, maintain version history, verify that agents use the latest approved information, flag responses based on outdated documents, and notify administrators when a knowledge base needs updating. This would be especially valuable in industries where accurate, current information is critical.
