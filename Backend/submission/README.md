# Submission evidence index

This folder separates immutable run evidence from submission-ready summaries.

| Item | File | Meaning |
|---|---|---|
| Final requirements audit | `FINAL_AUDIT.md` | Completed, partially evidenced, and student-only work. |
| Final report | `REPORT_FINAL.md` | The concise evidence-based report. |
| Two-page report source | `REPORT_TWO_PAGE_SOURCE.md` | Compact report source containing Tables 1, 2a, 2b, and 3 for final PDF export. |
| Submission packaging guide | `SUBMISSION_PACKAGE.md` | Required and excluded files plus final human checks. |
| Required tables | `REQUIRED_TABLES.md` | Tables generated from retained run data, including declared missing fields. |
| Raw schema audit | `CSV_AUDIT.md` | Confirms the exact required CSV columns and documents anomalies. |
| Clean submission data | `results_submission_clean.csv` | A non-destructive clean copy of `results.csv`; raw data is unchanged. |
| Retrieval grades | `retrieval_review.json` | 48 evaluated A/B/C answers with reviewer rationale and citations. |
| Retrieval comparison | `RETRIEVAL_COMPARISON.md` | Evidence supporting selection of setting B. |
| Groq baseline | `GROQ_BASELINE_SUMMARY.md` | Measured eight-call calibration, not fabricated provider capacity. |
| Stand-in validation | `STANDIN_VALIDATION.md` | Observed controlled 429, failure, SSE and load behavior. |
| C-setting investigation | `C_FAILURE_ANALYSIS.md` | Documents the real bi-encoder experiment, failure investigation, and regression correction. |
| Vaani template | `VAANI_FEEDBACK_TEMPLATE.md` | To be filled only with a genuine Vaani visit. |
| Conversation checklist | `CONVERSATION_HISTORY_CHECKLIST.md` | To be supplied only from actual, unedited student history and reflection. |
| Conversation export evidence | `CONVERSATION_EVIDENCE.md`, `conversation_evidence/` | Student-provided PDF/DOCX exports plus a hash register. |
| Final completion audit | `FINAL_EIGHT_TASK_REPORT.md` | Eight-task status with evidence and blockers. |
| Audit change log | `AUDIT_CHANGELOG.md` | Every final-audit code/data/documentation change and its verification. |
| CSV/table recomputation | `AUDIT_RESULTS_CSV.md`, `AUDIT_TABLES.md` | Independent recomputation from retained raw evidence. |
| Technical/slow-request audit | `AUDIT_TECHNICAL.md`, `AUDIT_SLOW_RETRY_RETRIEVAL.md` | Streaming, limits, scheduler, CSV and retrieval findings. |

Do not replace raw measurements with invented values. The two student-owned evidence items above must remain honestly marked pending until they are genuinely completed.
